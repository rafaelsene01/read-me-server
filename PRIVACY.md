# ReadMe — Privacy Policy

_Last updated: October 17, 2026_

ReadMe reads text aloud with synchronized highlighting. It has no accounts, no analytics, no ads and no tracking. The developer runs no server that receives your data.

## Data stored on your device

Everything ReadMe keeps stays in your browser's local extension storage:

- the text you capture from web pages, and the documents you import (EPUB, PDF, DOCX, text);
- your library, reading position, highlights, notes and bookmarks;
- your preferences (voice, speed, language, display);
- the neural voice models, downloaded once for offline use.

This data never leaves your device unless you use one of the optional features below. Removing the extension deletes it.

## Optional features that send data

Each of these runs only when you use it.

- **Google Translate** (off by default; Settings → "Use Google Translate"). When it is on and you ask for a translation, the text being translated and the target language are sent to Google (`translate.googleapis.com`). No URL, cookie, browsing history or personal information is sent. Google's processing is covered by the [Google Privacy Policy](https://policies.google.com/privacy). With the option off, translation runs on your device with Chrome's built-in Translator.
- **Feedback.** If you send feedback from the extension, the title and message you write are published, together with the extension version and your browser's user agent, as a **public** issue in the GitHub repository `rafaelsene01/read-me-server`. Do not include personal information in it. GitHub's processing is covered by the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

## Downloads

ReadMe downloads files without sending any of your data:

- neural voice models, from `huggingface.co`;
- the book catalog list, from `raw.githubusercontent.com`, and books from catalog servers you choose.

Like any download, these servers see your IP address.

## Permissions

ReadMe reads the content of a web page only when you ask it to capture that page, a selection or an element. It does not read pages in the background and does not collect browsing history.

## Sale and sharing

User data is never sold, and never used or shared for purposes unrelated to reading text aloud. It is never used for advertising or to determine creditworthiness.
